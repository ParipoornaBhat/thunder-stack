# Future Scope & Planned Enhancements

## Planned Capabilities
1. **Automated End-to-End Testing:**
   - Playwright integration for Next.js web application flows.
   - Vitest suite for Hono route validation and mock auth states.
2. **AI & Vector Extensions:**
   - pgvector schema integration for semantic search and embeddings directly inside `@thunder/db`.
3. **Advanced Telemetry & Tracing:**
   - OpenTelemetry integration for Cloudflare Workers and Hono request tracking.
4. **WebSocket / Real-Time Sync:**
   - Cloudflare Durable Objects or Supabase Realtime integration for instant live collaboration.
